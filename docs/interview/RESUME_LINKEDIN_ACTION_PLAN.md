I built a Fraud Alert Control Tower as a portfolio project focused on explainable banking analytics.

- data cleaning and feature engineering
- top-10 feature selection
- model comparison across five classifiers
- threshold tuning around investigator capacity
- local explanations for high-risk cases
- a Vercel static app
- model card and governance documentation

The biggest lesson: in financial services, a model is not enough. You also need threshold governance, explainability, human review, monitoring, and clear limitations.
